Manutenção

Como manter o painel atualizado

Atividades
Vêm do Jira (cards com a etiqueta plano-nov2026). A rotina do GitHub atualiza o arquivo data/jira.js todo dia útil às 7h.
Frente
Etiqueta frente-captacao, frente-pdi, frente-parcerias, frente-portfolio, frente-dados, frente-ict, frente-institucional, frente-programas ou frente-gestao.
Responsável
Etiqueta resp-diretor, resp-gerente ou resp-analista.
Parceiros
Arquivo data/parceiros.js: maturidade, áreas, interesses, situação e próximo passo.
Laboratórios
Vêm do repositório labs (embedded_data.js), copiados para data/labs.js pela mesma rotina.
